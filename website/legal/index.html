PRIVACY

Privacy

Nebula checks GitHub for new releases when it starts; Check at start on the SYSTEM page turns this off. DLSS and XeSS download from NVIDIA and Intel only when you choose them. Discord status connects only to the Discord app on your computer. Mods ask permission before using the internet, your files, the camera or the microphone.

After a benchmark, Nebula can send its results if you choose Send. The report holds your graphics card, processor, memory, system version, settings and the benchmark’s measurements, and is encrypted so only keepvaibin can read it. You can add the end of the game log, with names and paths removed. It never holds your user or computer name, file paths, serial numbers, saves, Miis or mods. The server uses your IP address only to limit how often one address can send, and does not store it. Reports are deleted after 180 days.

Crash reports and diagnostics recordings stay on your computer unless you attach them to a report.

This website has no analytics or accounts. Your browser reads the download count from GitHub. External sites such as GitHub and Discord have their own privacy policies.
