COMPATIBILITY

Supported mods

.luma mods, Riivolution packs, disc file replacements, Dolphin texture packs and replacement movies.

Wii code patches cannot run in a native game, and Nebula lists them at import. LumaLink converts a Wii mod to a .luma file and lists what it cannot use.

IMPORT

Installation

  1. 01

    Open Mods

    Open Settings, then the MODS page.

  2. 02

    Import

    Choose Import file or Import folder, or drop the mod on the game window. Archives can be .zip, .7z, .rar or .tar, without a password.

  3. 03

    Load order

    Move the mod to the list on the right. When two mods change the same file, the higher one wins.

  4. 04

    Apply

    Choose the mod’s options, then Apply and restart Nebula.

TEXTURES & MOVIES

Texture packs and movies

Dolphin texture packs use tex1_ file names. Texture packs On loads images as needed; Preload loads all of them at startup and uses more memory.

Replacement movies go in the movies folder, named like the game’s videos (for example PrologueA.mp4), as MP4, MKV or WebM. 4K video needs hardware video decoding.

TROUBLESHOOTING

Troubleshooting

Turn the mods off on the MODS page (on Windows, you can also hold Shift while Nebula starts). If the problem stops, turn the mods on one at a time. Error codes NEB-M01, NEB-M02 and NEB-M03 name the mod or file involved.
