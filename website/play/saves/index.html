BACK UP

Backups

Open Settings, then the GENERAL page, and choose Export saves. Choose where to keep the dated ZIP file.

IMPORT

Save import

  1. 01

    Find your save

    In Dolphin, right-click Super Mario Galaxy and choose Open Wii Save Folder.

  2. 02

    Import in Nebula

    Open Settings, then the GENERAL page. Choose Import saves and select GameData.bin in that folder.

  3. 03

    Replace and restart

    Choose Replace. Nebula moves your current save to a dated backup folder and restarts with the imported one.

Import saves also reads Wii SD card saves (data.bin), Switch saves (GameData.bin), Nebula.sav files and Nebula ZIP backups. Action Replay saves (.wii) cannot be read.

SAVE FILES

Save location

  • Windows: %LOCALAPPDATA%\Nebula\saves
  • Linux: ~/.local/share/Nebula/saves
  • macOS: ~/Library/Application Support/Nebula/saves
  • Android: inside the app. Use Export saves and Import saves.

Replaced saves move to a saves-backup-<date> folder beside the saves folder. Saves folder on the GENERAL page opens it.

Export a backup before a major update or a move to another computer.

MII ICONS

Mii icons

Import Miis on the GENERAL page adds Miis from a Wii, DS, 3DS, Wii U, Switch, Mii Studio or Mii Creator to the file icon list.
