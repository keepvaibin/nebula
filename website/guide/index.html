REQUIREMENTS

System requirements

Setup prepares the game from your own copy. Nebula includes no game files.

Requirement Nebula v2
Operating system Windows 10 (1803 or newer) or Windows 11, 64-bit; Linux with glibc 2.38 or newer (for example Ubuntu 24.04 or Fedora 39); macOS 12 or newer; Android 12 or newer
Processor x86-64 with SSE4.2, or ARM64. Processors with AVX2 use a faster build.
Graphics Direct3D 12 or 11 on Windows, Vulkan on Linux, Metal on macOS, Vulkan 1.1 on Android. Ray tracing needs a GPU with hardware ray tracing.
Memory 8 GB RAM (Windows, Linux, macOS)
Storage 8 GB free for setup
Your game Super Mario Galaxy for Wii, North America (RMGE01), revision 0. Super Mario Galaxy 2 is not supported.
Accepted formats ISO, RVZ or an extracted game folder

The North American disc plays in English, French and Spanish. Support for PAL and JP will come in v2.

INSTALL

Installation

  1. 01

    Download Setup

    Use the download page to get Nebula-Setup.exe.

  2. 02

    Choose your game

    Run Nebula-Setup.exe and select your game. Setup checks the disc and its revision.

  3. 03

    Install

    Choose Install. Setup prepares the game and adds Nebula to the Start menu.

  4. 04

    Play

    Open Nebula from the Start menu. The home screen has Play, Settings, Benchmark and Quit.

Download Nebula only from its GitHub releases. If Windows shows “Windows protected your PC”, choose More info, then Run anyway.

FIRST LAUNCH

First settings

Choose Settings on the home screen, or press F1 in the game. On controllers, press View + Menu (Xbox, Steam), Share + Options (PlayStation) or Minus + Plus (Switch).

  • Benchmark on the home screen recommends settings for your computer.
  • On an older computer, start at a low internal resolution and raise it while the game stays smooth.
  • Set Aspect ratio to Auto, and HUD resolution to Display for sharp menus and text.
  • On a display faster than 60 Hz, turn on Interpolation and set the target frame rate.
  • For ray tracing, start at Low or Medium. If the game slows down, lower the internal resolution or use an upscaler.
  • Choose Apply to keep changes, or Undo to discard them. Display changes revert after a countdown unless you keep them.

UPDATES

Updates

Nebula checks for updates at startup and shows them on the home screen. The SYSTEM page has Check for updates, and Check at start turns the startup check off. Updates and uninstalling keep your saves and settings.

  • Windows: choose Update. Nebula closes and Setup installs the new version. Run Setup again to repair, restore the previous version or uninstall.
  • macOS: choose Update, then Restart.
  • Linux: download the new package and run ./install.sh again.
  • Android: install the new app over the old one.

Before a major update, choose Export saves on the GENERAL page.
