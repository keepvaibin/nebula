OVERVIEW

Built from the decompilation

Nebula v2 runs Super Mario Galaxy as native code built from SMGCommunity’s Petari decompilation.

Setup reads your disc image and prepares the game files. It no longer compiles the game.

A closer look.

WHAT’S NEW

What’s new in v2

  • All US, PAL and JP languages, each through its own language’s ISO.
  • Windows (Direct3D 12 and 11), Linux and Android (Vulkan), and macOS (Metal).
  • A home screen with Play, Settings, Benchmark and Quit, and in-app updates.
  • DLSS, FSR 1, FSR 3, XeSS, SGSR 2 and MetalFX upscaling.
  • MSAA, SMAA and FXAA anti-aliasing, SSAO and GTAO ambient occlusion, enhanced lighting and HDR.
  • Interpolation above 60 Hz, with DLSS Frame Generation and FSR frame generation on supported GPUs.
  • PlayStation, Steam, Steam Deck and generic controllers, with gyro pointing on controllers with motion sensors.
  • Cutscene skip with a confirmation.
  • Dialogue speed up to Instant, including Rosalina’s storybook.
  • Separate volumes for music, effects, voices, ambience, cutscenes and the Wii Remote speaker.
  • Mods as .luma files made with LumaLink, and direct import of Riivolution and Dolphin texture packs.
  • Mii import for file icons.
  • Discord status with your current galaxy and mission.
  • Save import and export in the game, from a Wii, Dolphin or the Switch release.
  • Menus in all 14 of the game’s languages, and error codes with a saved report.
  • Ray-traced lighting is being worked on and will come in a very soon release.
