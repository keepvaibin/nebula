Common problems

No matching topics. Try another word or report the problem below.

Setup rejects my game

Nebula needs the North American release, RMGE01, revision 0. Modified or patched disc images fail the check. Support for PAL and JP will come in v2.

The game is slow

Lower the internal resolution, the ray tracing quality or the interpolation target, use an upscaler, or choose the Performance preset. See performance settings.

My controller is not detected

Reconnect the controller and set Input to Auto on the CONTROLS page. The Switch 2 Pro Controller needs the WinUSB driver on Windows. Check your controller.

DLSS or ray tracing is missing

DLSS needs an NVIDIA RTX GPU and a one-time download from NVIDIA, then a restart. Ray tracing needs a GPU with hardware ray tracing and a current driver. The SYSTEM page shows what this computer supports.

The game crashes with mods

Turn the mods off on the MODS page (on Windows, you can also hold Shift while Nebula starts), then turn them on one at a time. Read the mod guide.

The game will not start

Update your graphics driver. On a PC with two graphics cards, choose the other one under Graphics card on the SYSTEM page. If an error code appears, look it up below.

A replacement movie stutters

4K movies need hardware video decoding. Use a lower-resolution video.

Audio skips during play

Close programs using a lot of CPU time and try again. Include your hardware and background programs if the issue continues.

My save is missing

Check the dated saves-backup folders beside your saves folder. To bring a save back, use Import saves on the GENERAL page instead of copying files. Save backup and import guide.

Security warning on download

Download Nebula only from its GitHub releases. If Windows shows “Windows protected your PC”, choose More info, then Run anyway. If an antivirus flags a file, ask in Discord before you run it.

REPORT A BUG

Report a bug

Search the existing issues first. For a new problem, include the steps that cause it and what you expected.

  • Nebula version, for example 1.0.2.
  • Operating system, CPU, GPU and graphics driver version.
  • Galaxy and mission, plus the exact steps to reproduce the problem.
  • Graphics settings you changed and all enabled mods.
  • A screenshot or video for visual problems.

For a crash, attach the newest .txt and .dmp files from %LOCALAPPDATA%\Nebula\crasheson Windows, or the crashes folder in Nebula’s data folder elsewhere.

For a visual or timing problem, choose Record next to Diagnostics on the SYSTEM page, play until it happens, then attach the files from the diagnostics folder.
