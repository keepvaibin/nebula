Error codes

No matching codes. Try another word or use the bug report guide.

NEB-C01

The game’s code crashed with no mods in use.

What to try Start again. If it repeats at the same place, report it with the report files.

NEB-C02

The game stopped on one of its own checks. The report quotes its message.

What to try Start again. If it repeats at the same place, report it with the report files.

NEB-C03

The game’s code ran out of stack space.

What to try Start again. If it repeats at the same place, report it with the report files.

NEB-M01

The game crashed while mods were in use. The report lists them.

What to try Turn the mods off. If the crash stops, turn them on one at a time.

NEB-M02

The game crashed within 15 seconds of reading a mod’s file. The report names the mod and the file.

What to try Turn that mod off, or check that it matches your game’s region and version.

NEB-M03

The game crashed in a mod’s code. The report names the mod. Windows only.

What to try Turn that mod off and send its author the report files.

NEB-T01

A texture pack image stopped Nebula while loading. The report names the file.

What to try Remove the image from the pack, or save it again as a PNG.

NEB-V01

A replacement movie stopped Nebula while playing. The report names the file.

What to try Remove the video, or convert it to an H.264 MP4.

NEB-G01

The graphics driver reset the graphics card.

What to try Update the graphics driver. Turn off ray tracing or frame generation, or lower the internal resolution.

NEB-G02

The renderer stopped on another error. The report quotes it.

What to try Update the graphics driver. If it repeats, report it.

NEB-R01

Nebula ran out of memory.

What to try Close other programs, set Texture packs to On instead of Preload, or lower the internal resolution.

NEB-N01

Nebula’s own code crashed.

What to try Start again. If it repeats, report it.

NEB-N02

Nebula stopped on an unexpected error. The report quotes it.

What to try Start again. If it repeats, report it.

NEB-N03

Nebula stopped itself (abort).

What to try Start again. If it repeats, report it.

NEB-N04

Nebula stopped on an internal error while starting.

What to try Start again. If it repeats, report it.

NEB-S01

Nebula could not open the game content (game.pak).

What to try Open Nebula Setup and choose Repair.

NEB-S02

The game content is damaged.

What to try Run Nebula Setup again to rebuild it from your disc image.

NEB-S03

The game module is missing or from another Nebula version.

What to try Install or update Nebula again.

NEB-S04

The graphics card could not start the game.

What to try Update the graphics driver. With two graphics cards, choose the other one under Graphics card on the SYSTEM page.

NEB-S05

Nebula could not read its settings file.

What to try Rename config.ini in Nebula’s settings folder to start with default settings.

NEB-S06

Nebula was started with unknown arguments.

What to try Start Nebula from its shortcut or app menu entry.
