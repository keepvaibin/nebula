## About how-tos

Each article walks you through one task. For complete mods built from start to finish, see [Tutorials](../tutorials/index.md).

## Working on a mod

| Article | Description |
|---|---|
| [Creating a mod](creating-a-mod.md) | Create a mod folder with LumaLink, then add what the mod needs, its text in other languages, its options, its permissions and its files. |
| [Setting up an editor](setting-up-an-editor.md) | See errors, completion, and help for your mod's LumaScript as you type, in Visual Studio Code or any editor with a language server client. |
| [Testing a mod](testing-a-mod.md) | Write tests that start the game with your mod, play it for you, and check what happened, then run them with one command. |
| [Reloading a mod while playing](reloading-a-mod-while-playing.md) | Play your mod in dev mode so that each code change you save is built and reloaded in the running game. |
| [Reading the mod log](reading-the-mod-log.md) | Find out why a mod did not start or did not do what it should, from the notices in the game, the mod log page and the game's log. |
| [Packing and sharing a mod](packing-and-sharing-a-mod.md) | Pack a mod folder into one .luma file that players add to Nebula on any platform. |
| [Converting existing mods](converting-existing-mods.md) | Turn a mod made for the Wii, such as a Riivolution pack, a texture pack, or a Gecko code list, into a .luma that Nebula uses. |

## Adding content

| Article | Description |
|---|---|

| [Adding animations](adding-animations.md) | Replace the game's animations, add animations to your own models, name events at frames of an animation, and play animations from code. |
| [Writing material shaders](writing-material-shaders.md) | Give a model's material a look of its own with a short HLSL function, with values your code can change while the game runs. |
| [Adding particle effects](adding-particle-effects.md) | Make new particle effects, change the game's own, and start effects on objects from code. |
| [Adding sounds and music](adding-sounds-and-music.md) | Add sound effects and music to a mod, replace the game's sounds, voices and music, and play sounds from code. |
| [Adding screens and fonts](adding-screens-and-fonts.md) | Add screens of your own, such as a timer or a counter, change the game's screens, add fonts, and control screens from code. |
| [Changing Nebula's text and graphics](changing-nebulas-text.md) | Translate or reword the text Nebula adds to the game's screens, and change how those screens look. |
