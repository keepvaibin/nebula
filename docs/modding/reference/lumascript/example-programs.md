## About the example programs

Each tutorial builds one complete mod in LumaScript. The finished mods, with their tests, are in the documentation's `guides` folder.

| Program | What it shows |
|---|---|
| [Your first mod](../../tutorials/first-mod.md) | `use kit.hud`, a hook on the player's jump, a test file. |
| [A small tweak: six health](../../tutorials/a-small-tweak.md) | Changing one number of the game by its name. |
| [Hide the HUD](../../tutorials/hide-the-hud.md) | `option`, `on frame`, `hook before` with `skip`, `on option`. |
| [A new galaxy](../../tutorials/a-new-galaxy.md) | A stage, placements, models, enemies and a boss with `kit.stage`. |
| [A new character to talk to](../../tutorials/a-new-npc.md) | A character with a model, materials and dialogue with `kit.talk`. |
| [A new power-up: the Gold Flower](../../tutorials/a-new-power-up.md) | A form with `kit.player.form`, an item and a projectile. |
| [A video on a screen inside a galaxy](../../tutorials/a-video-in-a-galaxy.md) | The `movie` service. |
| [Balloon World](../../tutorials/balloon-world.md) | A game mode with menus, the HUD and `net.local` and `net.internet`. |
| [A ghost time trial with a replay viewer](../../tutorials/ghost-time-trial.md) | `kit.replay`, files and a menu of saved runs. |
| [LiveSplit link](../../tutorials/livesplit-link.md) | A TCP connection with `net.local`. |
| [An online leaderboard](../../tutorials/online-leaderboard.md) | `net.internet` as an optional service, menus and `save.global`. |
