## About the tutorials

Each tutorial builds one complete mod and explains its code as you go. The tutorials start small and grow in scope, so later tutorials assume you know the earlier ones.

Every tutorial includes a download of the finished mod, with its tests, so you can compare your work or build the mod as it is.

| Tutorial | Description |
|---|---|
| [Making a small tweak](a-small-tweak.md) | Change one of the game's numbers by name, so that Mario starts each level with six health instead of three. |
| [Hiding the HUD](hide-the-hud.md) | Remove the star, coin and life counters and the life meter from the screen, with an option to show them again. |
| [Changing a stage](a-stage-edit.md) | Add, change and remove objects in one of the game's stages with table patches alone, no code. |
| [Adding a level timer to the HUD](a-level-timer.md) | Add a screen of your own to the HUD, move one of the game's counters to make room, and show text in every language the game has. |
| [Adding a new object to a stage](a-new-object.md) | Make an object of your own, with its own model, ground Mario stands on and behaviour, and place it in one of the game's stages. |
| [Adding a new character to talk to](a-new-npc.md) | Add a character with its own model, materials and dialogue, and place it in Good Egg Galaxy. |
| [Adding a new power-up](a-new-power-up.md) | Add a Gold Flower that turns Mario gold and lets him throw bouncing gold balls. |
| [Playing as a new character](a-new-character.md) | Make a rigged model from any 3D tool into a character the game's animations move, and play it in Mario's place with its own moves, voice and jump. |
| [Playing in first person](first-person.md) | Put the camera in Mario's head, turn it with the mouse, the pointer, a gyro or a finger, and let Mario run where the player looks. |
| [Adding a new galaxy](a-new-galaxy.md) | Add a galaxy of your own, with its stage, enemies, a boss with its own cutscene and music, and text in every language. |
| [Playing a video inside a galaxy](a-video-in-a-galaxy.md) | Play your mod's movie when Mario walks up to a screen placed in a galaxy. |
| [Making a game mode: Balloon World](balloon-world.md) | Make a game mode with two halves, hiding a balloon for other players and finding the balloons they hid. |
| [Racing a ghost: a time trial with a replay viewer](ghost-time-trial.md) | Time and record every attempt at a star, race a ghost of your best run, and watch saved runs from the pause menu. |
| [Connecting to LiveSplit](livesplit-link.md) | Control LiveSplit, the speedrun timer, from the game over a local connection. |
| [Adding an online leaderboard](online-leaderboard.md) | Send each star's time to a leaderboard server, and show the fastest times from the pause menu. |
