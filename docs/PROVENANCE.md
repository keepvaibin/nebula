# Provenance

## Origin of this repository

Nebula's first public commit is a clean source snapshot. Its history starts
there; the earlier private development history (published under the name
GalaxyRecomp) is not carried forward because historical commits contained
local artifacts that must not be redistributed.

- Snapshot origin: private development revision
  `7aada18c39e489a4193faac72e0bc6c635f26e94`. Its runtime, recompiler and
  module headers are identical to the qualified visual release
  `49768b893fa4b9427d52c19db4622c82d966cff7` (later commits changed only
  documentation and diagnostic tools).
- Changes made for publication: product rename to Nebula; recompiler output
  made to reproduce the qualified release modules exactly (geometry hooks
  after their instruction blocks, movie-boundary PC publication, Home include
  order); new `identify`, `extract`, `generate`, `generate-dsp` and
  `package-content` commands; internal resolution limit raised from 6x to
  16x; installer, launcher and updater; removal of research sandboxes,
  evidence tooling, an unused Aurora source snapshot and internal notes.
- Author and copyright holder of the original work: the Nebula author
  (GitHub `keepvaibin`). Upstream contributions are attributed in
  `THIRD-PARTY-NOTICES.md` and in the ledger below.

## Known provenance uncertainties

These are recorded so they can be reviewed; Nebula does not claim blanket
legal clearance.

1. **Dusklight game-derived sources.** Several runtime policies were designed
   after reading Dusklight files under `src/d/`, `src/m_Do/` and
   `libs/JSystem/` (Twilight Princess decompilation). Dusklight's root CC0
   dedication does not establish rights in that underlying material. The
   ledger rows below state "design only / no upstream text copied" for these;
   the most code-shaped case is `runtime/include/galaxy/thp_audio_worker.h`,
   an independently written C++ queue modelled on the ownership pattern of
   `d_a_movie_player.cpp`. It contains no Twilight Princess structures.
2. **RMGE01 function boundaries.** `metadata/rmge01/functions.csv` contains
   only addresses and sizes, mechanically reduced from the CC0 Petari symbol
   configuration. Addresses and sizes are factual metadata of the user's own
   executable; no names, code or bytes are included.
3. **Wii common keys.** The `nod` disc library (MIT OR Apache-2.0) embeds the
   Wii common-key constants that every Wii disc reader (including Dolphin)
   uses to decrypt the user's own disc. They are compiled into
   `nebula-recomp.exe`. Their legal status is not established here.
4. **Hardware register and SDK layouts.** Guest structure layouts (KPAD,
   AX/DSP mailboxes, GX registers) are interface facts used for
   interoperability with the user's own game. They are written from public
   documentation and comparison, not copied SDK code.
5. **WiiCompiled-derived float experiment.** `ppc_float.cpp`'s fused paired
   arithmetic adapts a GPL-2.0-or-later Dolphin-derived header via
   WiiCompiled. It is compiled but disabled by default.

Not distributed by Nebula: Nintendo code or assets, disc images, extracted
game files, boot images, generated modules or sources, DSP ucode, saves,
shader caches, logs, captures, Microsoft toolchain files, CMake or Ninja.

## Ledger of adapted upstream implementation


## Header-visible scalar execution experiment — 2026-10-01

E04 uses WiiCompiled's header-visible arithmetic/register-barrier design at
`9b7b9913e4ab60b9c57fa4be56b8da308e76d06e`, exact ISA header SHA256
`FAE029B0931AB87EDD8740A3BA6DB8E02A52497C724FC5D2C42F3B16FF57467B`.
The file is GPL-2.0-or-later with the Dolphin2018 notice recorded below.
No reference implementation bytes are copied. Galaxy's existing13 local
math/status/commit bodies are shared in `ppc_float_native_inline.h` with
inline annotations, a private commit name and two equivalent widen-alias
spellings. The normalization operations and raw hashes are recorded in
`generated/ownership-scalar-inline-probe/prepared-patch.json`; raw definitions
are not byte-identical. `widen_f32` is exactly `return widen_f32_bits(bits)`.
Automatic operands/results transfer no memory ownership. ABI22 is unchanged;
precise status/fault ordering, original excluded-case fallback, public PPC
entries and checkpoint callbacks remain. A462624-case oracle against preserved
current libraries passes. AOT regeneration, compiled-code and live evidence
are still required. The flag defaults off and production rejects it.

## Fused paired binary arithmetic experiment — 2026-09-30

Reference: WiiCompiled `runtime/include/isa/ppc_isa_float.h` at verified
revision `9b7b9913e4ab60b9c57fa4be56b8da308e76d06e`, SHA256
`FAE029B0931AB87EDD8740A3BA6DB8E02A52497C724FC5D2C42F3B16FF57467B`.
The exact header is SPDX `GPL-2.0-or-later`, Copyright 2018 Dolphin Emulator
Project. `PpcMulPairInline`, `PpcAddPairInline` and `PpcSubPairInline` supply
the packed binary32 arithmetic approach, adapted in
`runtime/src/ppc_float.cpp::native_f32_paired_binary_fast`.
Galaxy's checks, exact binary64 status proof, layout, fallback and commit are
local. Context/service ABI structures are unchanged; captured uint32 operands,
vectors and lane results have automatic storage, with no ownership transfer.
The existing paired commit retains FPSCR union, lane0 FPRF and faults before
destination/CR writes. No timing, interrupt or framebuffer ownership changes.
The full module must be regenerated because opt-in Rust lowering calls the
new static helper. Focused differential tests and full AOT proof pass; four
clean captures found no accepted speed gain and the flag remains off.
The GPL-2.0-or-later contribution selects version 3 for this
GPL-3.0-only combined work; notices are retained in source and package notices.

## 2026-09-30 guest-frame button edge integration

**DSP routing follow-up:** Current Dusklight `DuskDsp.cpp::ApplyPanning` at
`40457c6adb381928e4b5fef6ed459ed291edd5e2`, file SHA256
`C5C7FCC2FC8B9FF4C6DD50812E2301BB0B52350A7448766185ACDDB22E3BEA54`,
CC0 native contributor code, selects stereo buses separately from effects.
The real Galaxy HLE trial rejected connected auxiliary routes `0x0DC0` and
`0x0E20` even with current/target gain zero and effect mix zero. Galaxy's
`native_audio_dusk_mix_stereo` now admits only this no-signal case. Audible
auxiliary ramps, unknown addresses and effects still fail. Native audio tests
compare every stereo sample with the valid baseline and retain those failures.
This is a bounded compatibility adaptation, not a native reverb replacement;
The updated adapter reaches visible Star Festival twice with zero audio queue
empties/sink errors, but full-route sound fidelity remains unverified. Native DSP stays default.

**Identity-filter follow-up:** Real trial `dusk_dsp_filter_detail_20260930_202720_52744_84ace49e9af8`
found mode `0x20`, AFC16/9, pitch `0x09FD`, with IIR coefficients
`{0x7fff,0,0,0,0,0,0,0}`. RMGE01's AOT native ucode at `0x0366..0x0384`
explicitly bypasses this identity shape. Galaxy independently adds a narrower
full-table identity check to the normalized Dusklight channel adapter and reads
the existing eight BE coefficient fields. No SDK code or upstream 48-kHz remap
was copied. Audio tests preserve every AFC sample and feedback for the identity
case; nontrivial IIR and any FIR remain unsupported. Two opt-in gameplay runs
survive the former rejection with unchanged matched artifacts (34.500649 and
33.300831 new XFB/s); these do not establish sound parity or a causal speed gain.
